# ポートフォリオ

https://portfolio.yuheiyamada.workers.dev/

## 技術スタック

Astro 5 / TypeScript / Tailwind CSS v4 / Cloudflare Workers

## コマンド

```sh
task dev             # 開発サーバーを起動
task build           # 本番用サイトをビルド
task preview         # 本番用サイトをビルドしてローカルで確認
task deploy          # Cloudflare Workersへデプロイ
task deploy:dry-run  # 公開せずにデプロイ内容を検証
```
